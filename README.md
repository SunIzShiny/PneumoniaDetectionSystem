<h3>Uses ResNet, DenseNet and MobileNet CNN models To train and combined them to get the final reliable output.</h3>
To Run:<br>
  import the necessary libraries.<br>
  Run the app.py<br><br>
Output Looks like this:<br>
lower percentage prediction -> Normal result<br>
higher percentage prediction -> Pneumonia result<br>
Final confidence score shows the average out of all 3 models combined.<br><br>
